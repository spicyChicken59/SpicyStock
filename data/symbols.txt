# SpicyStock scan universe — hand-curated starter list.
#
# WHAT THIS IS
#   A deliberately small, hand-written list of liquid US common stocks, read
#   by get_universe() in src/scanner.py in place of Alpaca's full ~11,000
#   symbol tradable-asset list. A full-market scan took 10-20 minutes; this
#   one takes seconds, which is the whole point — every later fix in the
#   rebuild has to be testable in one sitting.
#
# THIS SHOULD EVENTUALLY BE GENERATED — DO NOT TREAT IT AS AUTHORITATIVE.
#   These names were written out by hand, not fetched from an index or a
#   screener, so the list is already stale on the day it is committed:
#   tickers get renamed, companies merge, liquidity moves. A symbol that no
#   longer trades simply returns no bars and is skipped. The real fix is a
#   generator (index constituents plus a liquidity percentile — see the
#   step-4 percentile gate) that rewrites this file on a schedule and
#   records its source and date right here.
#
# WHAT IS IN IT
#   ~230 large- and mid-cap US common stocks, grouped by sector for human
#   reading only: get_universe() ignores the grouping and keeps file order.
#   Deliberately excluded:
#     - ETFs, ETNs, closed-end funds, and any leveraged or inverse product.
#       This screener rates single companies, not baskets.
#     - ADRs and foreign issuers — different home session, different data
#       quality on a free IEX feed.
#     - Biotech. That is rule 4 of the strategy (binary FDA events are not
#       momentum), and with fundamentals_filter() deleted, curating this
#       file is the only thing enforcing it — no code tests a sector. The
#       pharma/biotech line is a judgement call: large diversified pharma
#       (JNJ, LLY, MRK, PFE, ABBV, BMY) is kept, pure-play biotech is not.
#     - Class shares spelled with punctuation (BRK.B). Alpaca's exact
#       spelling for those could not be checked from this sandbox, and one
#       unrecognised symbol takes down its whole 100-name request batch.
#
# FORMAT
#   One ticker per line, A-Z, 1 to 5 characters. Blank lines are ignored.
#   `#` starts a comment, on its own line or trailing after a symbol.
#   Anything else is a hard error: get_universe() raises SymbolFileError
#   rather than skipping the line, so a typo cannot quietly shrink the
#   universe. A duplicated symbol is an error too.

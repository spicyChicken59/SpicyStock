## Four evidence classes

1. **ORIGINAL-PUBLICATION REPLAY:** exact original code/rules/inputs/replies.
   Verify what survived; absent raw replies or full universes remain absent.
2. **CURRENT-POLICY HISTORICAL SIMULATION:** frozen repair against the same
   observations; exact response reuse only when candidate/session/metrics/chart/
   prompt/rules/model identity is unchanged. New requests have UNKNOWN reviews.
3. **COMPONENT/EVENT STUDY:** candidate-selected frames may test arithmetic,
   signal stability, subsequent price observations and limited gate ablations.
   They are not a point-in-time universe or investable portfolio.
4. **SYNTHETIC ENGINEERING CONTROL:** existing production fixtures and isolated
   adversarial changes. No synthetic ticket or return enters live data/history.

## Operational baseline and execution/cost conventions

Test the existing after-close reaction / next-session entry variant, separate
from intraday day-one discovery, anticipation and EP9M. Freeze all baseline
numeric gates, reader prerequisite, selection count/model/retries/token ceilings,
membership and global actionability. Use the recorded model account for original
replay and the fixed default $10,000 / 0.5% risk / 25% cap / four slots for
isolated controls. Never use Tahir's personal capital.

Production planning selects the signal low then midpoint; the executable limit
is the lesser of the outer ceiling and floor-to-cents(stop/0.96), with stop below
trigger and positive cent-grid room above trigger. Independently check both
candidates, worst-limit sizing, whole shares, multipliers, cash and slots.
The published stop is planned price-to-stop risk, not a guaranteed maximum loss.

Production daily-bar open-in-band fill is a model convention, not a verified
stop-limit execution. Other possible fills retain uncertainty. Use actual
modeled fill for exit anchors. Keep partial-sale, stop-gap and same-bar ambiguity
explicit. Close-conditioned same-close exits have unattainable-information risk
unless an attainable execution assumption is established. Do not market such
results as executable performance. No invented intraday path or pace.

Where settlements support calculation, report gross and net R/return, mean and
median, losses/wins, missing/ambiguous/pending/unfilled counts. Cost scenarios are
0, 5 and 20 basis points per side on modeled traded notional (assumptions, not
measured costs); adverse stop-gap control is 1% below stop. Costs are applied to
each actual partial sale. Zero cost cannot be the sole conclusion. Daily overlap
and repeated symbols are dependent. No portfolio drawdown/exposure claim without
full chronological capacity/capital reuse and settlement modeling. SPY on matched
dates is context only, not an exposure-matched benchmark. Do not omit ambiguous
cases from the population while reporting only successful settlements.

## Limited comparisons and controls

Freeze baseline first, then demonstrated bug fixes on the identical population.
Attribute each changed decision. No threshold sweeps. Isolated counterfactuals:
GREEN, YELLOW, omitted reader gate, and both market+reader interventions; any
alternative allocation ranks only existing mechanically feasible candidates and
does not invent reviews. Keep all counterfactuals private/non-actionable. A rule
removal producing zero tickets does not prove the removed gate irrelevant.

Controls: append/alter future data; wrong symbol/session; changed volume and
digest; malformed/truncated reply; null versus false/zero; missing evidence/bars;
duplicate timestamps; insufficient lookback; split/basis mismatch; feasible and
infeasible cent bands; low/high prices; zero shares; slots/cash; open gaps;
intraday crossing; stop gaps; repeat execution; interrupted publication.
New regressions must fail on untouched affected code and an isolated restored
defect, with unchanged independent controls passing. Reuse existing meaningful
controls where applicable. Preserve all original evidence byte-for-byte.

## Data stop and release rule

Inventory full universes, candidate frames, benchmark, exception frames,
directories, raw replies, charts and later observations before claiming breadth
or performance. A long selected-stock history is not a historical universe.
If point-in-time membership, corporate-action identity or intraday execution data
are absent, record exact smallest acquisition proposal and continue independent
tests. No paid acquisition or new request is authorized. New policy choices stay
proposals; demonstrated contract violations may be repaired prospectively.

Ship one review PR with machine results, source manifest, honest gate table,
rendered evidence and checkpoint. No merge, dispatch, external message, live
scan or manual publication. A future normal production run is prospective
evidence only after it actually occurs.
